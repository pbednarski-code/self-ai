#Your self AI Agent with Gemini Api

Requirements
- Python 3.10+
- shell
- Gemini AI Studio account

Setup
- [ ] https://aistudio.google.com/api-keys 
- [ ] add yours key do .env
- [ ] download libraries

''''bash
python3 -m venv .venv
source .venv/bin/activate
pip install google-genai dotenv
''''


How to use? 
1. Set up your personal system message in main.py
2. Finally type """python main.py "your prompt" """ in terminal inside your project
